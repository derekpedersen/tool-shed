# Cloud Helpers

This module groups cloud-focused shell helpers and environment patterns for common developer workflows. Official docs: https://cloud.google.com/ and https://aws.amazon.com/

## What it is used for

- Loading shared cloud-related shell helpers into local environments
- Supporting cloud CLI workflows from a consistent bash profile
- Keeping cloud automation patterns discoverable alongside repo tools
- Providing a helper layer for local developer cloud setup

## Files

- bash.sh: cloud helper functions and shell aliases

## Usage

This is a helper-only module. Load it via the repo’s bash installer flow.
