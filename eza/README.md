# eza

eza is a modern, feature-rich replacement for the standard Unix `ls` command. Official site: https://github.com/eza-community/eza

## What it is used for

- Listing files with rich formatting and human-readable output
- Improving terminal navigation and file inspection workflows
- Providing a modern `ls` alternative for developer shell use
- Supporting local filesystem exploration with better defaults

## Files

- install.sh: install eza through the central installer runtime
- uninstall.sh: uninstall eza through the central installer runtime

## Usage

From repo root:

```bash
bash ./.tools/install.sh eza
bash ./.tools/uninstall.sh eza
```
