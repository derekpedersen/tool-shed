# fd

fd is a fast and friendly alternative to `find` for quick file and directory searching. Official site: https://github.com/sharkdp/fd

## What it is used for

- Searching files and directories quickly from the shell
- Finding project files without verbose `find` syntax
- Simplifying codebase navigation in local development
- Speeding up file-oriented shell workflows

## Files

- install.sh: install fd through the central installer runtime
- uninstall.sh: uninstall fd through the central installer runtime

## Usage

From repo root:

```bash
bash ./.tools/install.sh fd
bash ./.tools/uninstall.sh fd
```
