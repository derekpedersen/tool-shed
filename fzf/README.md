# fzf

fzf is a fuzzy finder for the terminal that makes searching and selecting files or command output fast and interactive. Official site: https://github.com/junegunn/fzf

## What it is used for

- Fuzzy finding files, commands, and project content interactively
- Improving shell workflows for file selection and filtering
- Making search-driven terminal tasks much faster
- Supporting quick local navigation and command discovery

## Files

- install.sh: install fzf through the central installer runtime
- uninstall.sh: uninstall fzf through the central installer runtime

## Usage

From repo root:

```bash
bash ./.tools/install.sh fzf
bash ./.tools/uninstall.sh fzf
```
