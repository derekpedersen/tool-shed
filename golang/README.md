# Go

Go is a fast, statically typed language designed for command-line tooling, cloud services, and backend systems. Official site: https://go.dev/

## What it is used for

- Building CLI tools and developer utilities
- Creating microservices and backend APIs
- Managing infrastructure and automation tooling
- Working with Go-based developer ecosystems and repositories

## Files

- install.sh: install Go through the central installer runtime
- uninstall.sh: uninstall Go through the central installer runtime
- install.windows.ps1: PowerShell wrapper for Go installation on Windows

## Aliases

Accepted alias names: go, golang

## Usage

From repo root:

```bash
bash ./.tools/install.sh golang
bash ./.tools/uninstall.sh golang
```

PowerShell (Windows):

```powershell
pwsh ./golang/install.windows.ps1
```
