# HTTPie

HTTPie is a user-friendly command-line HTTP client for testing APIs and interacting with web services from the shell. Official site: https://httpie.io/

## What it is used for

- Making HTTP requests to local and remote APIs
- Testing REST endpoints during development and debugging
- Working with JSON-based API interactions from the terminal
- Simplifying manual API verification in local workflows

## Files

- install.sh: install HTTPie through the central installer runtime
- uninstall.sh: uninstall HTTPie through the central installer runtime

## Usage

From repo root:

```bash
bash ./.tools/install.sh httpie
bash ./.tools/uninstall.sh httpie
```
