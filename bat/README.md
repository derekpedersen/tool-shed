# bat

bat is a syntax-highlighted, Git-aware replacement for the shell `cat` command. Official site: https://github.com/sharkdp/bat

## What it is used for

- Viewing files with syntax highlighting in the terminal
- Inspecting code and config files more clearly than plain `cat`
- Working with Git-aware file previews in local development
- Improving shell productivity for read-heavy workflows

## Files

- install.sh: install bat through the central installer runtime
- uninstall.sh: uninstall bat through the central installer runtime

## Usage

From repo root:

```bash
bash ./.tools/install.sh bat
bash ./.tools/uninstall.sh bat
```
