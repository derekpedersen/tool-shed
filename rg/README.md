# ripgrep

ripgrep (`rg`) is a fast text-search tool for code and files, designed for developer workflows and large repos. Official site: https://github.com/BurntSushi/ripgrep

## What it is used for

- Searching code and text quickly across large repositories
- Finding symbols, strings, and file patterns in local projects
- Supporting fast shell-based code navigation and debugging
- Replacing slower, heavier search tools in dev workflows

## Files

- install.sh: install ripgrep through the central installer runtime
- uninstall.sh: uninstall ripgrep through the central installer runtime

## Usage

From repo root:

```bash
bash ./.tools/install.sh rg
bash ./.tools/uninstall.sh rg
```
