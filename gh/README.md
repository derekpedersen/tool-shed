# GitHub CLI

The GitHub CLI (`gh`) lets you work with GitHub repositories, pull requests, issues, and workflows directly from the terminal. Official site: https://cli.github.com/

## What it is used for

- Creating and reviewing pull requests from the shell
- Managing issues, releases, and repository metadata
- Working with GitHub Actions and CI from local workflows
- Supporting terminal-first GitHub productivity and automation

## Files

- install.sh: install GitHub CLI through the central installer runtime
- uninstall.sh: uninstall GitHub CLI through the central installer runtime

## Usage

From repo root:

```bash
bash ./.tools/install.sh gh
bash ./.tools/uninstall.sh gh
```
