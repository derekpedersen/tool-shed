# Java

Java is a general-purpose programming language and runtime used for JVM-based applications, backend services, and developer tooling. Official site: https://www.java.com/en/

## What it is used for

- Running Java applications and JVM-based services
- Building and testing enterprise backend applications
- Supporting toolchains such as Maven, Gradle, and Spring Boot
- Local developer environments for Java-focused projects

## Files

- install.sh: install Java through the central installer runtime
- uninstall.sh: uninstall Java through the central installer runtime

## Aliases

Accepted alias names: java, jdk, openjdk, temurin

## Usage

From repo root:

```bash
bash ./.tools/install.sh java
bash ./.tools/uninstall.sh java
```

Dry run:

```bash
bash ./.tools/install.sh java --dry-run
bash ./.tools/uninstall.sh java --dry-run
```
